# SILVERCHAT — PROMPT #12: CALLS (VOICE & VIDEO)

You are a senior full-stack engineer implementing **real-time voice and video
calls** for SilverChat using LiveKit Cloud. This is the last major feature of
the roadmap.

This prompt covers: calls tab, call log, incoming call modal, outgoing call
modal, active call UI (voice + video), LiveKit Edge Function for tokens,
permission handling, call state machine.

**Not covered here**: group calls (Fase 2), call recording (Fase 2),
screen sharing (Fase 2), call quality indicators (Fase 2), push notifications
(Fase 2 → Prompt #13).

All decisions are **final and locked**.

## 1. LOCKED DECISIONS

| #   | Decision                                                                     |
| --- | ---------------------------------------------------------------------------- |
| L1  | **Ring timeout: 15 seconds** (not 30)                                        |
| L2  | Ringtone + calling tone from `public/sounds/` (MP3, ~30KB each)              |
| L3  | Incoming call: fullscreen modal, pulsing avatar, accept/decline, countdown   |
| L4  | Voice call: pulsing ring during ringing, circular waveform when speaking     |
| L5  | Video call: remote fullscreen + local PiP + floating glass controls          |
| L6  | Request camera/mic permissions BEFORE connecting to LiveKit                  |
| L7  | State transitions: ringing → answered → ended / missed / declined / canceled |
| L8  | Call log: All / Missed filters, grouped by day (Today / Yesterday / Date)    |
| L9  | FAB with active chats list + search → tap → starts voice call (default)      |
| L10 | Edge Function `livekit-token` validates membership + generates JWT           |
| L11 | Frontend detects peer disconnect via LiveKit → UPDATE call to `ended`        |
| L12 | Auto-reject incoming call if already in a call (status `missed`)             |

Additional locked decisions:

- **1:1 calls only in MVP.** Group calls are Fase 2.
- **LiveKit Cloud** (free tier: 10k min/mo, 100 concurrent participants).
- **No push notifications** — incoming calls only ring if the recipient has
  the app open in a tab. Fase 2 (Prompt #13) will add Web Push.
- **Auto-reject busy**: if the user is in an active call and a new call comes
  in, it is immediately marked `missed` (never shown).
- **Video defaults**: 720p max, 30fps cap, VP9 codec preferred.
- **Audio**: Opus, 48kHz, DTX enabled.
- **LiveKit Room name format**: `call_{call_uuid}` generated by the `start_call`
  RPC.
- **Call log shows the last 100 calls** (Fase 2: paginate).

-- ═══════════════════════════════════════════════════════════════
-- 2. RPC: START CALL (atomic: generates room name + inserts row)
-- ═══════════════════════════════════════════════════════════════
CREATE OR REPLACE FUNCTION start_call(
  p_chat_id uuid,
  p_type call_type
)
RETURNS uuid
LANGUAGE plpgsql SECURITY DEFINER
SET search_path = public
AS $$
DECLARE
  v_call_id uuid;
  v_room_name text;
BEGIN
  -- Must be a chat member
  IF NOT is_chat_member(p_chat_id, auth.uid()) THEN
    RAISE EXCEPTION 'Not a member of this chat';
  END IF;

  -- Chat must be active (per #4b-1 policy on calls)
  IF NOT is_chat_active(p_chat_id) THEN
    RAISE EXCEPTION 'Cannot call in a pending or rejected chat';
  END IF;

  -- Chat must be direct or self (not group / community_chat in MVP)
  IF NOT EXISTS (
    SELECT 1 FROM public.chats
    WHERE id = p_chat_id AND type IN ('direct', 'self')
  ) THEN
    RAISE EXCEPTION 'Calls are only supported in direct chats';
  END IF;

  -- Check for an already-active call in this chat
  IF EXISTS (
    SELECT 1 FROM public.calls
    WHERE chat_id = p_chat_id AND status IN ('ringing', 'answered')
  ) THEN
    RAISE EXCEPTION 'A call is already in progress in this chat';
  END IF;

  -- Check the caller is not already in another active call
  IF EXISTS (
    SELECT 1 FROM public.calls c
    JOIN public.chat_members cm ON cm.chat_id = c.chat_id
    WHERE cm.user_id = auth.uid()
      AND c.status IN ('ringing', 'answered')
      AND c.initiator_id <> auth.uid()
  ) OR EXISTS (
    SELECT 1 FROM public.calls
    WHERE initiator_id = auth.uid() AND status IN ('ringing', 'answered')
  ) THEN
    RAISE EXCEPTION 'You are already in a call';
  END IF;

  v_room_name := 'call_' || gen_random_uuid()::text;

  INSERT INTO public.calls (
    initiator_id, chat_id, type, status, livekit_room_name
  ) VALUES (
    auth.uid(), p_chat_id, p_type, 'ringing', v_room_name
  )
  RETURNING id INTO v_call_id;

  RETURN v_call_id;
END;
$$;
GRANT EXECUTE ON FUNCTION start_call(uuid, call_type) TO authenticated;

import { serve } from 'https://deno.land/std@0.168.0/http/server.ts';
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';
import { AccessToken } from 'https://esm.sh/livekit-server-sdk@2';

const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers':
    'authorization, x-client-info, apikey, content-type',
  'Access-Control-Allow-Methods': 'POST, OPTIONS',
};

serve(async (req) => {
  if (req.method === 'OPTIONS') {
    return new Response('ok', { headers: corsHeaders });
  }

  try {
    const supabase = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_ANON_KEY')!,
      {
        global: {
          headers: { Authorization: req.headers.get('Authorization')! },
        },
      }
    );

    const { data: { user }, error: authError } = await supabase.auth.getUser();
    if (authError || !user) {
      return new Response(JSON.stringify({ error: 'unauthorized' }), {
        status: 401,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    const { call_id } = await req.json();
    if (!call_id || typeof call_id !== 'string') {
      return new Response(JSON.stringify({ error: 'call_id required' }), {
        status: 400,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    // Validate call via service role (bypass RLS for atomic check)
    const adminClient = createClient(
      Deno.env.get('SUPABASE_URL')!,
      Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!
    );

    const { data: call, error: callError } = await adminClient
      .from('calls')
      .select('id, chat_id, livekit_room_name, status, started_at')
      .eq('id', call_id)
      .single();

    if (callError || !call) {
      return new Response(JSON.stringify({ error: 'call not found' }), {
        status: 404,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    if (!['ringing', 'answered'].includes(call.status)) {
      return new Response(JSON.stringify({ error: 'call not active' }), {
        status: 400,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    // Must be recent (< 5 min old)
    const callAge = Date.now() - new Date(call.started_at).getTime();
    if (callAge > 5 * 60 * 1000) {
      return new Response(JSON.stringify({ error: 'call expired' }), {
        status: 400,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    // Must be a chat member
    const { data: member } = await adminClient
      .from('chat_members')
      .select('chat_id')
      .eq('chat_id', call.chat_id)
      .eq('user_id', user.id)
      .maybeSingle();

    if (!member) {
      return new Response(JSON.stringify({ error: 'not a chat member' }), {
        status: 403,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      });
    }

    // Generate LiveKit JWT
    const at = new AccessToken(
      Deno.env.get('LIVEKIT_API_KEY')!,
      Deno.env.get('LIVEKIT_API_SECRET')!,
      { identity: user.id, ttl: '15m' }
    );
    at.addGrant({
      roomJoin: true,
      room: call.livekit_room_name,
      canPublish: true,
      canSubscribe: true,
      canPublishData: true,
    });

    const token = await at.toJwt();

    return new Response(
      JSON.stringify({
        token,
        url: Deno.env.get('LIVEKIT_URL'),
        room: call.livekit_room_name,
      }),
      {
        status: 200,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      }
    );
  } catch (err) {
    console.error('[livekit-token]', err);
    return new Response(
      JSON.stringify({ error: 'internal', detail: String(err) }),
      {
        status: 500,
        headers: { ...corsHeaders, 'Content-Type': 'application/json' },
      }
    );
  }
});

Grouping by day (in callFormatter.ts):

ts
type CallGroup = { label: string; calls: Call[] };

function groupCallsByDay(calls: Call[], locale: string): CallGroup[] {
  const today = new Date().toDateString();
  const yesterday = new Date(Date.now() - 86400000).toDateString();
  const groups = new Map<string, Call[]>();

  for (const call of calls) {
    const d = new Date(call.started_at);
    const dayKey = d.toDateString();
    if (!groups.has(dayKey)) groups.set(dayKey, []);
    groups.get(dayKey)!.push(call);
  }

  return Array.from(groups.entries()).map(([dayKey, items]) => {
    let label: string;
    if (dayKey === today) label = 'Today';
    else if (dayKey === yesterday) label = 'Yesterday';
    else label = new Intl.DateTimeFormat(locale, {
      day: 'numeric', month: 'short', year: 'numeric',
    }).format(new Date(dayKey));
    return { label, calls: items };
  });
}

ts
useEffect(() => {
  const channel = supabase
    .channel('incoming-calls')
    .on('postgres_changes',
      { event: 'INSERT', schema: 'public', table: 'calls' },
      async (payload) => {
        const call = payload.new;
        if (call.initiator_id === userId) return; // my own call
        if (call.status !== 'ringing') return;
        const age = Date.now() - new Date(call.started_at).getTime();
        if (age > 15000) return; // stale, ignore

        // Is the user a member of this chat?
        const { data: member } = await supabase
          .from('chat_members')
          .select('chat_id')
          .eq('chat_id', call.chat_id)
          .eq('user_id', userId)
          .maybeSingle();
        if (!member) return;

        // Fetch the other user's profile
        const { data: chat } = await supabase
          .from('chats')
          .select('id, chat_members(user_id)')
          .eq('id', call.chat_id)
          .single();
        const otherUserId = chat?.chat_members
          .find(m => m.user_id !== userId)?.user_id;
        const { data: otherUser } = await supabase
          .from('profiles_visible')
          .select('id, username, display_name, avatar_url, last_seen_at')
          .eq('id', otherUserId!)
          .single();

        // Busy check
        if (callStore.getState().phase !== 'idle') {
          await supabase.from('calls').update({
            status: 'missed',
            decline_reason: 'busy',
            ended_at: new Date().toISOString(),
          }).eq('id', call.id);
          return;
        }

        // Enter incoming phase
        callStore.setState({
          phase: 'incoming-ringing',
          call, otherUser, ringStartedAt: new Date().toISOString(),
        });
      })
    .subscribe();

  return () => { supabase.removeChannel(channel); };
}, [userId]);

9.1 Accept flow (incoming)

async function acceptCall() {
  const { call } = callStore.getState();
  if (!call) return;

  try {
    // 1. Request permissions FIRST
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: true,
      video: call.type === 'video',
    });
    stream.getTracks().forEach(t => t.stop()); // we'll re-acquire via LiveKit

    // 2. Update call status to answered
    await supabase.from('calls').update({
      status: 'answered',
      answered_at: new Date().toISOString(),
    }).eq('id', call.id);

    // 3. Move to answered phase (ActiveCallModal/ActiveVideoCallModal mounts)
    callStore.setState({
      phase: 'answered',
      answeredAt: new Date().toISOString(),
    });

    // 4. Connect to LiveKit (handled by useLiveKitRoom inside ActiveCallModal)
  } catch (err: any) {
    if (err.name === 'NotAllowedError' || err.name === 'PermissionDeniedError') {
      showPermissionError();
    } else {
      toast.error('Failed to start call. Try again.');
      declineCall('canceled');
    }
  }
}
9.2 Outgoing call flow
ts
async function startCall(chatId: string, type: 'voice' | 'video') {
  try {
    // 1. Request permissions FIRST
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: true,
      video: type === 'video',
    });
    stream.getTracks().forEach(t => t.stop());

    // 2. Create the call row via RPC
    const { data: callId, error } = await supabase.rpc('start_call', {
      p_chat_id: chatId,
      p_type: type,
    });
    if (error) throw error;

    // 3. Fetch the call + other user
    const { data: call } = await supabase
      .from('calls')
      .select('*, chat:chats!calls_chat_id_fkey(*)')
      .eq('id', callId)
      .single();
    // ... fetch otherUser

    // 4. Enter outgoing-ringing phase
    callStore.setState({
      phase: 'outgoing-ringing',
      call, otherUser, ringStartedAt: new Date().toISOString(),
    });
  } catch (err: any) {
    if (err.name === 'NotAllowedError') showPermissionError();
    else toast.error(err.message ?? 'Failed to start call');
  }
}

        if (updated.status === 'answered') {
          callStore.setState({
            phase: 'answered',
            answeredAt: updated.answered_at,
          });
        } else if (['declined', 'missed', 'canceled'].includes(updated.status)) {
          handleCallEnded(updated);
        }
      })
    .subscribe();

  return () => { supabase.removeChannel(channel); };
}, [phase, call?.id]);
9.4 Hangup
ts
async function hangup(reason: 'hangup' | 'peer_hangup' = 'hangup') {
  const { call, room, phase } = callStore.getState();
  if (!call) return;

  callStore.setState({ phase: 'ending' });

  try {
    // Disconnect from LiveKit
    if (room) await room.disconnect();

    // Update DB
    const update: any = {
      status: 'ended',
      ended_at: new Date().toISOString(),
      ended_reason: reason,
    };

    if (phase === 'outgoing-ringing') {
      // I canceled before answer
      update.status = 'canceled';
      update.decline_reason = 'canceled';
    } else if (phase === 'incoming-ringing') {
      update.status = 'declined';
      update.decline_reason = 'declined';
    } else if (phase === 'answered' && call.answered_at) {
      update.duration_seconds = Math.floor(
        (Date.now() - new Date(call.answered_at).getTime()) / 1000
      );
    }

    await supabase.from('calls').update(update).eq('id', call.id);
  } catch (err) {
    console.error('[hangup]', err);
  } finally {
    callStore.getState().reset(); // back to idle
  }
}

13. HOOK: useLiveKitRoom(callId, mode)
Encapsulates the entire LiveKit lifecycle.

ts
export function useLiveKitRoom(callId: string, mode: 'voice' | 'video') {
  useEffect(() => {
    let room: Room | null = null;
    let cancelled = false;

    async function connect() {
      // 1. Fetch token from Edge Function
      const res = await fetch(
        `${import.meta.env.VITE_SUPABASE_URL}/functions/v1/livekit-token`,
        {
          method: 'POST',
          headers: {
            'Content-Type': 'application/json',
            Authorization: `Bearer ${(await supabase.auth.getSession()).data.session?.access_token}`,
          },
          body: JSON.stringify({ call_id: callId }),
        }
      );
      if (!res.ok) throw new Error('Failed to get LiveKit token');
      const { token, url } = await res.json();

      // 2. Create room
      room = new Room({
        adaptiveStream: true,
        dynacast: true,
        videoCaptureDefaults: { resolution: VideoPresets.h720.resolution },
      });

      // 3. Wire up events → callStore
      room
        .on(RoomEvent.ParticipantConnected, (p) => {
          // Bind remote tracks
          p.on('trackSubscribed', (track) => {
            if (track.kind === Track.Kind.Video) {
              callStore.setState({ remoteVideoTrack: track as RemoteVideoTrack });
            } else if (track.kind === Track.Kind.Audio) {
              callStore.setState({ remoteAudioTrack: track as RemoteAudioTrack });
              track.attach(); // autoplay audio
            }
          });
          p.on('trackUnsubscribed', (track) => {
            track.detach();
            if (track.kind === Track.Kind.Video) callStore.setState({ remoteVideoTrack: null });
            if (track.kind === Track.Kind.Audio) callStore.setState({ remoteAudioTrack: null });
          });
          // Audio level (for waveform)
          p.on('audioLevelChanged', (level) => {
            callStore.setState({ remoteAudioLevel: Math.round(level * 100) });
          });
        })
        .on(RoomEvent.LocalAudioLevelChanged, (level) => {
          callStore.setState({ localAudioLevel: Math.round(level * 100) });
        })
        .on(RoomEvent.Disconnected, () => {
          hangup('peer_hangup');
        });

      // 4. Connect
      await room.connect(url, token);
      if (cancelled) {
        room.disconnect();
        return;
      }

      // 5. Publish local tracks
      await room.localParticipant.setMicrophoneEnabled(true);
      await room.localParticipant.setCameraEnabled(mode === 'video');

      // Store room + local tracks in callStore
      callStore.setState({
        room,
        localAudioTrack: room.localParticipant.getTrackPublication(Track.Source.Microphone)?.track as LocalAudioTrack ?? null,
        localVideoTrack: room.localParticipant.getTrackPublication(Track.Source.Camera)?.track as LocalVideoTrack ?? null,
        isMicEnabled: true,
        isCameraEnabled: mode === 'video',
      });
    }

    connect().catch((err) => {
      console.error('[useLiveKitRoom]', err);
      toast.error('Failed to connect to call');
      hangup('network_lost');
    });

    return () => {
      cancelled = true;
      room?.disconnect();
    };
  }, [callId, mode]);
}
Note: room.localParticipant.getTrackPublication(...)?.track — the exact
API may differ by SDK version. Use @livekit/components-react hooks like
useTracks if simpler.
