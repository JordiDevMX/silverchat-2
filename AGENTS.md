# SilverChat working agreements

- **CON-006 — Quality and autonomy:** work step by step, favor quality, and adapt architectural suggestions to the existing implementation. Preserve business/data contracts. Extract workflows into hooks/lib and pass the app typecheck before changing their JSX. Respect the user-approved migration scope and stop at its review boundary.
- **CON-007 — Commit discipline:** commit each completed task/unit of work with a clear message referencing affected `UI_MIGRATION_MAP.md` IDs. Keep commits coherent and exclude unrelated user changes. The one-time verified Phase 2.1/Module 1 baseline is commit `ff3b4eb`.
- **CON-008 — Browser review, no image artifacts:** do not generate or save screenshots/PNG images for visual review, including failure screenshots in browser harnesses. Functional browser assertions are allowed. Handoffs must list exact routes/fixture states, viewport sizes, themes and accents for users to inspect through `pnpm dev` and devtools device emulation.
